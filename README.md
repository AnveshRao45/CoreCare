# CoreCare

Flutter Android app for health tracking, meal planning, and on-device AI (Gemma).

## Setup

```bash
flutter pub get
flutter run
```

## Stack

- Flutter / Dart
- Hive (local storage)
- Riverpod
- Health Connect (Android vitals)
- Google ML Kit (workout rep counting)
- llama_flutter_android (on-device meal plans + chat)

## Note

Download the Gemma model from the app on first use. Model files are not stored in this repo.
